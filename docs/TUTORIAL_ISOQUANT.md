# Tutorial: IsoQuant-corrected reads

`run-isoquant` analyzes corrected long-read transcript evidence generated by IsoQuant.

## Sample sheet

```text
sample\tcondition\tisoquant_dir
C1\tcontrol\t/path/C1_isoquant
C2\tcontrol\t/path/C2_isoquant
T1\ttreated\t/path/T1_isoquant
T2\ttreated\t/path/T2_isoquant
```

## Run

```bash
java -jar APAURA.jar run-isoquant \
  --samples isoquant_samples.tsv \
  --gtf annotation.gtf \
  --control control \
  --case treated \
  --out isoquant_results
```

IsoQuant mode shares the direct/long-read APA framework. Use:

```bash
java -jar APAURA.jar run-isoquant --help
```

for the exact supported options in the installed JAR.
